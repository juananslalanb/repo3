# Módulo Universitario: Algoritmos y Estructuras de Datos 📚💻

> Repositorio oficial y material de estudio para el curso de **programacion**, diseñado para estudiantes de ingeniería, ciencias de la computación y carreras afines.

---

## 🎯 Objetivo del Módulo

Este módulo tiene como propósito fundamental desarrollar el **pensamiento computacional** y la capacidad de resolución de problemas en los estudiantes. Al finalizar el curso, serás capaz de diseñar, analizar y traducir algoritmos eficientes a código real utilizando buenas prácticas de programación.

---

## 🗂️ Estructura del Repositorio

El contenido está organizado de manera progresiva en las siguientes carpetas temáticas:

```text
/
├── 01-Introduccion/        # Conceptos básicos, pseudocódigo y diagramas de flujo.
├── 02-EstructurasControl/  # Estructuras secuenciales, condicionales y ciclos.
├── 03-Funciones/           # Modularidad, paso de parámetros y recursividad.
├── 04-EstructurasDatos/    # Arreglos (Arrays), Matrices, Listas, Pilas y Colas.
├── 05-AlgoritmosBusqueda/  # Búsqueda lineal y búsqueda binaria.
├── 06-AlgoritmosOrden/     # Método burbuja, selección, inserción y mergesort.
└── Proyectos/              # Prácticas integradoras y retos de programación.
